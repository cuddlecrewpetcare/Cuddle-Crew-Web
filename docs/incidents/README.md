# Meaningful Incident Records

Create a dated Markdown record here only for a meaningful security, privacy, production-write, provider, or availability incident. Do not record routine local test failures. Keep every record public-repository-safe unless an approved private incident system is selected.

Use this minimal structure:

```text
# YYYY-MM-DD — Safe incident title

- Severity:
- Category:
- Affected component/provider:
- Time window:
- Safe summary and impact:
- Writes or unknown outcomes:
- Evidence preserved (safe locations/identifiers only):
- Root cause:
- Containment/remediation:
- Validation:
- Follow-up, owner, and due state:
```

Never include credentials, raw headers or payloads, contact details, addresses, access/medical/payment data, private provider URLs, internal acceptance reasoning, or identifying incident evidence. Store sensitive evidence in an approved access-controlled location and reference only a safe opaque identifier here.
