Archived prompts and summaries are lower authority than safety, welfare, law, insurance, approved Service scope, current signed Client-facing policy, approved Client-specific Precise Petcare records, current approved business references, and current application implementation. Use the complete hierarchy in `../../business-reference/guidance/source-of-truth-document-hierarchy.md`.

Before using any artifact, compare it with current `github/main`, `AGENTS.md`, current approved business references, completed work, and later reconciliations. Do not use a historical prompt to revive stale behavior or duplicate completed foundation work.

## Provenance labels

- `EXACT` — exact original prompt text was recovered without modernization.
- `RECONSTRUCTED` — working intent was rebuilt from other evidence because exact text was unavailable.
- `REVISED` — a later replacement or reconciliation prompt, not the original prompt.
- `SUMMARY ONLY` — only a bounded synopsis of recovered intent is available.

No archived Phase 12 artifact currently has `EXACT` provenance. Do not upgrade a provenance label without locating and preserving the exact source separately.

See `CURRENT-RECONCILIATION.md` for the current non-authoritative disposition and `MANIFEST.md` for the archive inventory.
